## 📖 About The Project

**Product Store** is an intuitive e-commerce frontend interface built entirely with modern **Vanilla Web Technologies**. The application demonstrates real-time DOM manipulation, dynamic data rendering, asynchronous operations, and array processing without relying on heavy external frameworks or libraries.

Designed with simplicity and performance in mind, it provides users with an effortless shopping interface while serving as a clean, modular reference for core JavaScript fundamentals.

---

## ✨ Key Features

- 🔍 **Real-Time Search:** Instant product filtering as you type.
- 🗂️ **Category Filtering:** Easily filter items by specific categories or view all products.
- 🔀 **Smart Sorting:** Sort products dynamically by price (ascending/descending) or alphabetically.
- 📱 **Fully Responsive:** Optimized layout adapting seamlessly across desktop, tablet, and mobile devices.
- ⚡ **Zero Dependencies:** Ultra-fast load times leveraging raw Vanilla JavaScript, CSS3, and HTML5.

## 🚀 Getting Started

No build tools or heavy package installations required. You can run this project locally in seconds:

### 1. Clone the repository
```bash
git clone https://github.com/a00ae/Product-Store.git
```

### 2. Navigate to the project directory
```bash
cd Product-Store
```

### 3. Open in Browser
- Simply double-click `index.html` to open it in your default web browser.
- *(Recommended)* Or use the **Live Server** extension in Visual Studio Code for real-time live reloading.
